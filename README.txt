ZIZZVERSE Website — starter package

Files:
- index.html: responsive one-page website with embedded CSS and SEO metadata.
- favicon.svg: simple ZIZZVERSE browser icon.

Before publishing:
1. Replace the AH monogram placeholder with your real portrait.
2. Add only genuine social profile links or a public business email if you want them shown.
3. Once you have a domain, add the canonical URL and og:url in the <head>.
4. Add the final public website URL and portrait URL to the structured data (Person/ProfilePage) and Open Graph image metadata.
5. Review the bio so every statement accurately describes you.

Publish with GitHub Pages:
1. Create a GitHub repository named zizzverse (public for a free GitHub Pages project site).
2. Upload index.html and favicon.svg to the repository root.
3. Open Settings > Pages and select Deploy from a branch, branch main, folder /(root).
4. Save and wait for the published URL.
5. Add that exact URL in Google Search Console and request indexing.

Note: Search indexing and a Google Knowledge Panel are not guaranteed. The site uses sample bio wording and a portrait placeholder, so personalize it before publication.
